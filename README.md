# 🚀 CS Fundamentals: C Programming & Algorithms

This repository contains my implementations of fundamental computer science concepts using the **C programming language**. 

As a Computer Engineering student, I believe mastering C is crucial for understanding how software interacts with hardware, managing memory efficiently, and writing optimized code before moving to high-level languages like Python or JavaScript.

## 🛠️ Key Concepts Covered
In this collection, I focused on the core aspects of low-level programming:

- **Pointers & Memory Management:** Understanding `malloc`, `calloc`, `free`, and pointer arithmetic to prevent memory leaks.
- **Data Structures:** Implementation of linked lists, stacks, queues, and binary trees from scratch.
- **Algorithms:** Sorting (Bubble, Quick, Merge Sort) and searching algorithms aimed at understanding Big O complexity.
- **File I/O:** Reading from and writing to external files for data persistence.
- **Structs & Unions:** Organizing complex data types efficiently.

## 📂 Repository Structure

- `Algorithms/` - Sorting and searching implementations.
- `DataStructures/` - Linked Lists, Stacks, and Queue codes.
- `Pointers_Memory/` - Exercises focused on dynamic memory allocation.
- `File_Operations/` - Projects involving reading/writing .txt or .dat files.
- `Mini_Projects/` - (Buraya varsa o ders için yaptığın ufak oyun veya otomasyon ödevini koyabilirsin, örn: Student Management System)

## 💻 Why C?
Building these projects helped me solidify my understanding of:
1. How the stack and heap work.
2. The cost of abstraction in higher-level languages.
3. Writing bug-free code without a garbage collector.
